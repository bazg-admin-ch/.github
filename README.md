# BAZG Open Source

Das Bundesamt für Zoll und Grenzsicherheit (BAZG) veröffentlicht hier den Quellcode seiner Anwendungen gemäss Art. 9 des Bundesgesetzes über den Einsatz elektronischer Mittel zur Erfüllung von Behördenaufgaben (EMBAG).

## Hintergrund

- Das EMBAG verpflichtet Bundesbehörden, den Quellcode ihrer Software offenzulegen, soweit keine Rechte Dritter oder Sicherheitsgründe dagegen sprechen: https://www.fedlex.admin.ch/eli/cc/2023/682/de
- Veröffentlicht wird jeweils ein bereinigter Stand der Anwendung. Interne Entwicklungshistorie, interne Adressen und Zugangsdaten sind nicht Teil der Veröffentlichung.
- Die Repositories werden regelmässig aktualisiert.

## Lizenz

Die Anwendungen stehen unter der Apache License 2.0, sofern im jeweiligen Repository nichts anderes steht.

## Beiträge und Sicherheit

- Die Repositories sind schreibgeschützt. Beiträge, Issues und Pull Requests aus der Öffentlichkeit werden nicht entgegengenommen.
- Sicherheitslücken melden Sie bitte gemäss der Datei SECURITY.md im jeweiligen Repository.
